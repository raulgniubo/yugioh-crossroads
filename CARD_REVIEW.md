# Card review list

Made by comparing each card's printed text with the rules the game runs for it.
A card is on this list when its text has more parts than its rules do, so it probably plays a simplified version.
This is a machine-made first pass: some cards here are fine, and it does not cover Spells and Traps yet.
Every card in the game passes the card drill (`tools/card_drill.gd`): its rules do fire. This list is about whether they say everything the card says.

211 effect monsters with hand-written rules were compared. 90 are listed below, biggest gap first.
